# 工单台主题

生成或修改界面之前：

1. 读仓库根目录的 `DESIGN.md`。色值、字体、圆角、分层和签名以那份文件为准，实现对照 `src/styles.css`。
2. 确认视觉主题：`qingge`（青格）、`kanci`（刊次）或 `yingbian`（硬边）。没指定时，沿用页面当前的 `data-theme`。不要发明第四套。
3. 确认版面：`reading`（阅读）、`product`（产品）或 `infra`（运维）。没指定时，沿用当前的 `data-surface`。版面只改疏密和信息结构，不改该主题的色值、字体家族、圆角和分层。
4. 不要把主题和版面绑在一起。刊次可以是运维，硬边可以是阅读。文档里的建议搭配只是提示。
5. 只使用该主题已经锁定的一套视觉。不要使用折角、蓝绿纸底单据，或上一版的色值。
6. 浅色和深色只通过 `data-scheme="light|dark"` 切换。硬边的深色仍是粗边加无模糊偏移阴影。
7. 文案用简体中文。西文走西文字体，汉字走 Noto 或思源。焦点环在浅底、深底和实心强调按钮上都要看得见。
8. 同一元素只用该主题规定的一种分层：青格是短阴影加明度差，刊次是线和纸层，硬边是 3px 实线加 `6px 6px 0` 无模糊阴影。运维页的绿、黄、红只表示状态。
