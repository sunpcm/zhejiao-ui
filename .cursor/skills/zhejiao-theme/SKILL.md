# 工单台主题

生成或修改界面之前：

1. 读仓库根目录的 `DESIGN.md`。色值、字体、圆角、分层和签名以那份文件为准，实现对照 `src/styles.css`。
2. 确认主题：`qingge`（青格）、`kanci`（刊次）或 `yingbian`（硬边）。没指定时，沿用页面当前的 `data-theme`。
3. 只使用该主题已经锁定的一套。不要发明第四套，不要把三套合成一套，不要使用折角、蓝绿纸底单据，或上一版的色值。
4. 浅色和深色只通过 `data-scheme="light|dark"` 切换。硬边的深色仍是粗边加无模糊偏移阴影。
5. 文案用简体中文。焦点环在浅底、深底和实心强调按钮上都要看得见。
6. 同一元素只用该主题规定的一种分层：青格是短阴影加明度差，刊次是线和纸层，硬边是 3px 实线加 `6px 6px 0` 无模糊阴影。
