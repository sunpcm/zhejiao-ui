# 折角

写任何界面之前，按这个顺序做：

1. 读 `DESIGN.md`。
2. 读 `src/tokens.css`（或目标项目里拷过去的那一份）。
3. 列出这次会用到的令牌名字。没有对应令牌，就先补令牌，不要在组件里写新的色值、字号、圆角。
4. 再写界面。

## 必须遵守

- 只用浅色和深色。不要加第三套主题。
- 颜色、字体、字号、间距、圆角都用令牌。禁止新起色板。
- 界面字体是 Noto Sans SC。长文是 Noto Serif SC。代码和数字是 IBM Plex Mono。
- 面板圆角 2px，控件圆角 4px。不要出现 16px 以上的圆角。
- 层次用 1px 边线。不要加软阴影，不要 `rgba(0, 0, 0, 0.1)` 铺在每块上。
- 折角只用一次。目标项目里如果已经有一处，不要再加。
- 文案用真实中文，例如需求走到交付、店铺巡检、会话记录。禁止 Lorem，禁止占位英文口号。
- 阅读行宽控制在约 66ch，不要拉成通栏长句。
- 键盘焦点必须看得见。动效只给用户触发的反馈；尊重 `prefers-reduced-motion`。

## 禁止

不要使用，也不要当成替代方案推荐：

- Inter、Roboto、Open Sans、Lato、Arial、Space Grotesk
- 紫色、靛色、紫罗兰渐变，渐变字，发光按钮
- 卡片套卡片，大圆角加软阴影，悬停抬起，每个区块淡入上移
- 表情当图标，全大写字距眉题，装饰用的 01、02、03
- 「词语 — 半句」标签，用间隔号串起来的装饰性元信息
- Introducing、The future of
- 奶油底加赤陶色，纯黑底加荧光绿
- 报纸通栏、首字下沉、两端对齐的仿古排版
- shadcn/ui，或 Tailwind 默认的锌色加紫色套件

图标用简单描边或排印符号，不用表情。
